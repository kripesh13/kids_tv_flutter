1. Executive Project Summary

This architectural document guides the complete end-to-end development of the **Kids Entertainment Streaming Platform** backend in **Laravel**. The backend powers two high-performance client applications developed in Flutter:

  • Flutter Mobile App: Android & iOS with touch navigation, responsive layouts for smartphones and tablets.
  • Android TV App: Big-screen landscape navigation, remote control D-pad focus management, and hardware video playback.

The Laravel backend serves two core purposes:

  1. High-Throughput RESTful API: Delivers video streaming manifests (HLS .m3u8 / MP4), YouTube content, Live TV feeds, dynamic category listings, user favorites, video likes, and continue watching timestamps.
  2. Rich Web Admin Dashboard (Filament v3): Allows non-technical administrators to manage categories, upload/link universal media, configure authentication gates per category, and toggle global platform feature permissions.

Key Architectural Requirement: Dual User States

The mobile and TV platforms support Guest Users with zero-friction browsing. Guests can immediately browse public categories and watch public videos without creating an account. Interaction features (Favorites, Likes, Watch History, and restricted categories configured by the Admin) trigger authentication prompts.

2. System Architecture & Component Flow

1. Client Layer (Flutter) Mobile (iOS/Android) & Android TV Apps. Handles caching, D-pad remote focus, video rendering.
→
2. Gateway / Middleware Laravel Routing, Rate Limiting, auth:sanctum (Optional Bearer token for guests), CORS.
3. API Controller Layer Validates requests, delegates to Services, transforms models via Laravel API Resources.
→
4. Filament v3 Admin Panel Livewire/Tailwind admin dashboard for CMS, user management, and category authentication switches.
5. Data & Storage Layer PostgreSQL / MySQL, Redis (Caching & Views count), AWS S3 / Cloudflare R2 (Thumbnails & Video storage).

4. RESTful API Endpoints Specification

All endpoints return standardized JSON formatted for the Flutter mobile & TV repositories.

4.1 Authentication Endpoints (Laravel Sanctum)

Method Endpoint Auth Description
POST /api/v1/auth/register Public Registers member: name, email, password. Returns User + Sanctum Bearer token.
POST /api/v1/auth/login Public Authenticates with email and password. Returns User + Sanctum token.
POST /api/v1/auth/logout Sanctum Revokes current access token.
POST /api/v1/auth/forgot-password Public Sends password reset email link.
GET /api/v1/auth/profile Sanctum Fetches current user profile and role.

4.2 Content & Streaming Endpoints

Method Endpoint Auth Description
GET /api/v1/categories Optional List visible categories. Returns requires_login flag so client can enforce lock icon.
GET /api/v1/categories/{id} Optional Category details + video list. If category has requires_login: true and user is unauthenticated, returns 403 Forbidden with code LOGIN_REQUIRED.
GET /api/v1/content Optional Filterable content: ?category_id=...&is_featured=1&search=...&page=1.
GET /api/v1/content/{id} Optional Video details: streaming URL, likes count, is_liked (if auth), is_favorite (if auth).
POST /api/v1/content/{id}/views Public Atomically increments view counter (buffered in Redis).
GET /api/v1/banners Public Active home featured banners for carousel.
GET /api/v1/live-channels Public Active 24/7 TV channels (HLS m3u8 + MP4 web fallback).
GET /api/v1/youtube-channels Public Curated YouTube superstars channel listings.
GET /api/v1/features/permissions Public Returns key-value map of feature auth requirements.

4.3 Member Interactions (Authenticated User Only)

Method Endpoint Auth Description
GET /api/v1/user/favorites Sanctum List user saved favorite videos.
POST /api/v1/user/favorites/{content_id} Sanctum Toggles favorite status (returns {is_favorite: bool}).
POST /api/v1/user/likes/{content_id} Sanctum Toggles video like (returns {is_liked: bool, likes_count: int}).
GET /api/v1/user/watch-history Sanctum List continue watching items sorted by latest activity.
POST /api/v1/user/watch-history Sanctum Upserts playback position: content_id, position_seconds, total_duration_seconds.
DELETE /api/v1/user/watch-history Sanctum Clears personal watch history.

5. Filament v3 Admin Panel Design

Filament v3 is the recommended admin framework for Laravel 11. It provides a lightning-fast, reactive TALL stack (Tailwind, Alpine, Laravel, Livewire) interface:

5.1 Category Resource Configuration

Admins control guest restrictions directly from the form:

// app/Filament/Resources/CategoryResource.php
Forms\Components\TextInput::make('name')->required()->live(onBlur: true)
    ->afterStateUpdated(fn ($set, $state) => $set('slug', Str::slug($state))),
Forms\Components\ColorPicker::make('color_hex')->default('#6657E8'),
Forms\Components\FileUpload::make('thumbnail_url')->image()->directory('categories'),
Forms\Components\Section::make('Access & Security Controls')->schema([
    Forms\Components\Toggle::make('is_visible')->label('Enable Category')->default(true),
    Forms\Components\Toggle::make('requires_login')
        ->label('Require User Login (Guest Gate)')
        ->helperText('Guests will be prompted to sign in when clicking this category')
        ->default(false),
    Forms\Components\Toggle::make('is_featured')->label('Show on Homepage')->default(false),
    Forms\Components\Toggle::make('allow_favorites')->label('Allow Favorites')->default(true),
    Forms\Components\Toggle::make('allow_sharing')->label('Allow Sharing')->default(true),
])->columns(2);

5.2 Universal Content Management Resource

  • Polymorphic Content Support: Switch input fields based on content_type:
    • video: Direct file upload to S3/Cloudflare R2 or direct MP4 URL.
    • youtube_video / youtube_channel: YouTube video ID or Channel URL.
    • live_stream: M3U8 HLS stream URL with MP4 fallback.
  • Bulk Actions: Bulk publish, unpublish, change category, feature/unfeature.
  • Analytics Column: Live view counts and like counter badges in table row.

5.3 Feature Permissions Page

A custom Filament settings page providing an interactive toggle matrix for the 9 platform features. Toggling a switch immediately updates the feature_permissions table, instantly restricting or permitting guest users in the mobile and TV apps.

6. Step-by-Step Implementation Roadmap

Phase 1: Project Setup & Database Foundations

  • Create fresh Laravel 11 project: composer create-project laravel/laravel kids-tv-api
  • Install packages: composer require laravel/sanctum filament/filament:^3.2 spatie/laravel-permission
  • Configure .env with PostgreSQL or MySQL and Redis cache.
  • Run database migrations for users, categories, content_items, banners, live_channels, youtube_channels, feature_permissions, favorites, likes, and watch_history.
  • Seed default categories and initial feature permission matrix.

Phase 2: Authentication & Access Control Services

  • Configure Laravel Sanctum for API token issuance and SPA cookie auth.
  • Implement CategoryAccessMiddleware: blocks guests when requires_login = true.
  • Implement FeatureAccessMiddleware: checks feature_permissions table for guest restrictions.
  • Create AuthController with register, login, profile, and logout endpoints.

Phase 3: Public & Streaming APIs

  • Implement CategoryController, ContentController, BannerController, LiveChannelController, YoutubeChannelController.
  • Build Laravel API Resources (CategoryResource, ContentItemResource) matching the exact JSON format expected by the Flutter clients.
  • Implement buffered view incrementing via Redis to prevent database write bottlenecks.

Phase 4: Filament v3 Admin Panel

  • Install Filament: php artisan filament:install --panels
  • Generate resources: CategoryResource, ContentItemResource, BannerResource, LiveChannelResource, UserResource.
  • Build FeaturePermissions custom page with reactive toggles.
  • Configure authorization policies so only role = 'admin' can access /admin.

Phase 5: Cloud Storage & Video Streaming Optimization

  • Configure S3/Cloudflare R2 driver for video and thumbnail uploads.
  • Add Cloudflare Stream or AWS CloudFront CDN caching headers for HLS streaming.
  • Test with high-concurrency requests using Laravel Octane (FrankenPHP or Swoole).
